git restore - отменят все незакомиченные файлы 
 git checkout <хеш> - переход на конкретный коммит
 HEAD detached - показывает на каком комите находишься 
 git revert - отменяет определенный коммит не меняя историю 
 git switch -c - создание новой ветки с переходом в данную ветку
 git merge - обьединение изменении с другими ветками
 fast-forward - перемещение указателя ветки без нового коммита и создания новой ветки
 git branch -d - удаление ветки с которой перенесены данные в основную ветку
 Конфликт слияния - Когда выпала одинаковая строка в двух ветках при слиянии Git не может выбрать правильный вариант
 
merge request - запрос на слияние изменений , для того чтобы другие разработчики проверили и одобрили 
Ревью - для того чтобы второй разработчик проверил работу и нашел ошибки
Почему второй мerge request получил конфликт - потому что оба разработчика изменили одну и ту же строку в файле Readme из за чего вышла ошибка в Git
Как решил: git switch main
git pull
git switch add-walks
git merge main
удаление маркеров в README.md
git add README.md
git commit -m "Merge branch 'main' into add-walks"
git push
